## Project Overview

The Modeling Academy is a website project designed for a fictional modelling academy. The website provides information about the academy, its programmes, events, student success stories, registration process, and contact information.

The main purpose of the website is to provide aspiring models with an easy-to-use platform where they can learn about the academy, its programmes and available opportunities.

## Website Goals and Objectives

The main goals of the website are to:

* Recruit new students.
* Provide information about modelling programmes.
* Allow visitors to register their interest online.
* Showcase student success stories.
* Promote upcoming modelling events and activities.
* Provide contact and enquiry information.
* Improve the online visibility of The Modeling Academy.

### Key Performance Indicators (KPIs)

* Increase website visitors.
* Increase online enquiries.
* Increase student registrations.
* Increase engagement with the academy's social media platforms.
* Improve the response process through online enquiry forms.

## Website Pages

The website currently contains the following nine pages:

1. **Home (****`index.html`****)** – Introduces The Modeling Academy and provides an overview of the organisation.
2. **About Us (****`about.html`****)** – Provides information about the academy, including its mission, vision and values.
3. **Programs (****`programs.html`****)** – Displays the modelling programmes offered by the academy and describes what students can learn.
4. **Gallery (****`gallery.html`****)** – Displays images and videos of modelling activities, training sessions and academy events.
5. **Success Stories (****`success-stories.html`****)** – Contains fictional student testimonials and success stories.
6. **Events (****`events.html`****)** – Provides information about upcoming workshops, fashion shows and other academy activities.
7. **Registration (****`registration.html`****)** – Contains an online registration form for students interested in joining the academy.
8. **Contact (****`contact.html`****)** – Provides contact information and an enquiry form.
9. **FAQ (****`faq.html`****)** – Answers common questions about the academy, programmes and registration.

## Responsive Breakpoints

The stylesheet uses three viewport ranges:

* **Desktop:** 769px and wider. The main content can use a two-column grid, and gallery sections can display three columns.
* **Tablet:** 481px to 768px. The layout changes to one column, navigation links stack vertically, and typography scales down.
* **Mobile:** 480px and narrower. Typography, page padding, and the logo size are reduced to fit smaller screens.

These breakpoints are implemented in `CSS/style.css` using `@media (min-width: 769px)`, `@media (max-width: 768px)`, and `@media (max-width: 480px)`.
